🏦 Bank/Insurer/NBFC — valued with the Excess Return Model

DCF is not used for bank/insurer/NBFC stocks: deposits, reserves, or loan origination are a raw material rather than funding, so there's no clean free cash flow. This company also retains most of its earnings for growth instead of paying them out, so the Dividend Discount Model would understate its value -- the Excess Return Model is used instead, valuing (ROE − Cost of Equity) × Book Value each year on top of the existing book value.
